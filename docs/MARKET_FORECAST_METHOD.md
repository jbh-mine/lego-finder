# 현재 시세와 미래 가격 추정법

화면의 숫자는 현재 판매 통계, 자동 추세 모형, 사용자가 넣은 가정으로 구분한다. 미래 가격을 보장하지 않으며 출시가·부품 수·테마 이름으로 존재하지 않는 시세를 만들어 넣지 않는다.

## 현재 가격

선택한 제품·New/Used·판매자 지역·KRW에 대해 BrickLink sold 응답에서 조회 시점까지 **최근 30일의 유효한 가격 행 전체**를 고른다.

```text
현재 시세 P0 = median(최근 30일 주문 행의 unit_price)
가격 프리미엄(%) = (현재 시세 ÷ 비교 가능한 한국 공식 발매가 - 1) × 100
```

중앙값은 행별 비가중 값이다. 두 중간값이면 산술평균한다. 표본 수는 선택된 익명 가격 행 수이며 판매 수량이나 완전한 거래 건수가 아니다. 최근 30일 자료가 없으면 P0를 제공하지 않는다. 최근 6개월 평균·수량 가중 평균, 최저 판매 호가는 별도 참고 값이다. 호가를 거래 가격으로 바꾸지 않는다.

KRW는 공급원이 반환한 표시 통화다. GLOBAL은 전 세계 판매자, KR은 한국 소재 판매자 필터이며 국내 소비자 시세 전체가 아니다. New는 세부 미개봉·완전성 보증이 아니다. 원통화·환율·배송비·세금·수수료가 온전히 제공되지 않으므로 해외 공급원 가격과 한국 발매가로 자동 투자 수익률을 만들지 않는다. [출처의 정확한 범위](MARKET_DATA_SOURCES.md)

## 자체 관측 이력으로 추세 추정

조회할 때 P0와 표본 수를 **UTC 하루 한 점**으로 저장한다. 같은 날 재조회는 점을 덮어쓴다. 공급원에서 다시 받은 동일 주문 행을 새 거래로 누적하지 않는다. 같은 제품·상태·판매자 지역·통화·계산 기준끼리만 사용한다.

1. 일별 가격 관측값을 달력 월별 중앙값 `Mᵢ`로 집계한다. 겹치는 30일 창과 잦은 조회가 독립 표본처럼 과장되는 일을 줄이지만 자기상관을 완전히 없애지는 못한다.
2. 6개 이상의 유효한 월 구간, 일별 관측 기간 180일 이상, 최근 관측 30일 이내, 현재 가격 캐시 유효 조건을 모두 검사한다. 누락·오래된 가격·불명확한 조건은 자동 추정을 막는다.
3. 월의 대표 시점을 15일로 두고 첫 월부터 지난 시간을 연 단위 `tᵢ`로 계산한다. 자연로그 가격을 최소제곱 직선에 맞춘다.

```text
yᵢ = ln(Mᵢ)
b = Σ[(tᵢ - 평균t)(yᵢ - 평균y)] / Σ[(tᵢ - 평균t)²]
a = 평균y - b × 평균t
추정 연 변화율(%) = (exp(b) - 1) × 100
h년 후 참고 가격 P(h) = P0 × exp(b × h)
```

현재의 실제 P0에서 시작해 과거 월별 로그 추세의 기울기만 적용한다. 모델은 3년·5년을 3개월 간격으로 표시한다. 회귀 잔차가 수치상 거의 없거나 계산이 발산하면 숫자를 표시하지 않는다.

참고 범위는 잔차 표준편차 `s`와 회귀의 외삽 불확실성을 이용한다. `n`은 월 구간 수, `Sxx=Σ(tᵢ-평균t)²`, `t현재`는 현재 조회 시점이다.

```text
E(h) = 2s × sqrt[1 + 1/n + (t현재 + h - 평균t)² / Sxx]
범위 = [P(h) × exp(-E(h)), P(h) × exp(E(h))]
```

이는 **확률이 검증되지 않은 모형 참고 범위**다. 95% 신뢰구간이나 실제 투자 손익의 하한·상한이 아니다. 월별 데이터의 자기상관, 표본 편향, 환율, 거래량 변화, 재발매, 제품 상태 혼합, 큰 시장 충격을 예측하지 못한다. 180일만 쌓인 자료로 3~5년을 외삽하면 특히 불확실하다. 이 기간 기준은 사용 가능 여부의 최소 조건이며 정확도 보증이 아니다.

## 사용자 가정 시나리오

자동 추정이 아직 불가능해도 확인된 현재 시세가 있으면 사용자가 연 변화율·수수료·고정 비용을 입력할 수 있다. 기본 연 변화율은 0%이며 추천 수익률이 아니다.

```text
미래 총액 = P0 × (1 + 사용자가 입력한 연 변화율 / 100)^기간
예상 수령액 = 미래 총액 × (1 - 수수료율 / 100) - 고정 비용
```

현재 시세가 없으면 이 시나리오에도 임의의 시작 가격을 넣지 않는다. KREAM 7종 공개 스냅샷은 출처·관측일·상태가 다른 별도 자료이며 BrickLink 자동 시계열과 합치지 않는다.
